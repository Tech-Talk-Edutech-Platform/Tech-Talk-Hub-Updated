## 1. What is Scratch?

### 🤖 Byte Explains

Scratch is a free coding website where **YOU are the creator!**

Instead of typing complicated code, you connect colourful blocks to build your programs.

### 💻 Byte Shows You How

Go to [scratch.mit.edu](https://scratch.mit.edu).

You can create:

* 🎮 Games
* 🎬 Animations
* 📖 Stories
* 🎂 Digital cards
* 🎵 Music projects

Millions of young creators around the world use Scratch to create and share projects.

![Scratch Website](SCRATCH_WEBSITE_IMAGE_URL)

### 💭 Byte Asks

If you could create **ANY Scratch project**, what would you make?

### 💡 Remember This

> **Scratch = create with code blocks.
> Blocks = your code.
> Imagination = your only limit!**

## 2. The Scratch Interface

### 🤖 Byte Explains

The Scratch screen has different areas for finding blocks, building code, and watching your project run.

### 💻 Byte Shows You How

* **Menu Bar** — File, Edit, and Tutorials.
* **Tabs** — Code, Costumes, and Sounds.
* **Blocks Palette** — where you find coding blocks.
* **Code Area** — where you connect your blocks.
* **Stage** — where your project comes to life.
* **Sprite Pane** — where you manage your sprites.

![Labelled Scratch Interface](SCRATCH_INTERFACE_IMAGE_URL)

### 💭 Byte Asks

Which tab would you click to change how your sprite looks?

### 💡 Remember This

> **Blocks Palette = find blocks.
> Code Area = build code.
> Stage = watch it happen!**

---

## 3. Sprites and Backdrops

### 🤖 Byte Explains

Think of Scratch like a little theatre.

**Sprites are the actors. Backdrops are the scenery.**

### 💻 Byte Shows You How

A **sprite** can be a cat, rocket, cake, ball, or almost any character or object.

A **backdrop** is the scene behind your sprites, such as a forest, space, or birthday party.

Use **Choose a Sprite** to add a character and **Choose a Backdrop** to change the scene.

Sprites can move around the Stage using **x (left–right)** and **y (up–down)** positions.

![Sprite and Backdrop Example](SPRITE_BACKDROP_IMAGE_URL)

### 💭 Byte Asks

If your project took place in space, what sprite and backdrop would you choose?

### 💡 Remember This

> **Sprite = character or object.
> Backdrop = scenery.
> Stage centre = x: 0, y: 0.**

---

## 4. Events — When Green Flag Clicked

### 🤖 Byte Explains

Events tell Scratch **when something should happen**.

Think of an event like a doorbell: something happens, and your code starts running!

### 💻 Byte Shows You How

The **when green flag clicked** block starts a script when you press the green flag.

```text
when green flag clicked
say [Hello!] for (2) seconds
```

You can also use:

```text
when this sprite clicked
```

This makes code run when the player clicks the sprite.

### 💭 Byte Asks

What do you think happens if a script has no event block to start it?

### 💡 Remember This

> **Event = tells code when to start.
> Green flag = start the project!**

---

## 5. Looks Blocks — Say and Think

### 🤖 Byte Explains

Looks blocks control how your sprite looks, speaks, and thinks.

They are the purple blocks in Scratch.

### 💻 Byte Shows You How

```text
say [Hello!] for (2) seconds
```

Creates a speech bubble.

```text
think [Hmm...] for (2) seconds
```

Creates a thought bubble.

**Say = talking.**
**Think = thinking.**

### 💭 Byte Asks

Which block would you use if your sprite was thinking about cake but didn't want to say it aloud?

### 💡 Remember This

> **Say = speech bubble.
> Think = thought bubble.
> Both are Looks blocks!**

---

## 6. Motion and Color Effects

### 🤖 Byte Explains

Motion blocks make sprites move, while graphic effects change how sprites look.

### 💻 Byte Shows You How

```text
go to x: (0) y: (0)
```

Moves the sprite immediately.

```text
glide (0.3) secs to x: (100) y: (50)
```

Moves the sprite smoothly.

```text
change [color] effect by (25)
```

Changes its colour.

```text
clear graphic effects
```

Returns the sprite to normal.

### 💭 Byte Asks

Which would you choose if you wanted your sprite to move smoothly: **go to** or **glide**?

### 💡 Remember This

> **Go to = instant move.
> Glide = smooth move.
> Color effect = change colour.
> Clear effects = back to normal!**

# 🏠 Assignment: World Map Explorer

### 🎯 Mission

Build an interactive world map with **7 marker sprites — one for each continent**.

When someone clicks a marker, it should say the name of that continent.

---

## 📖 Story

Byte has started a journey around the world! 🌍🤖

But Byte needs your help keeping track of all the places visited.

Your mission is to place a marker on each of the **seven continents** and program every marker to reveal the continent's name when clicked.

Can you build Byte's interactive **World Map Explorer**?

---

## 🚀 Getting Started

* Open your Scratch project and choose a **world map backdrop**.
* Add one **Marker** sprite.
* Duplicate it until you have **7 markers**.
* Remember the blocks you used in class: `when this sprite clicked`, `say`, and `go to x: y:`.
* 💡 **New skill:** Right-click a sprite and choose **Duplicate** to quickly create a copy.

---

## 🗺️ Build Your Explorer

### 1. Prepare Your World

Add a **world map backdrop** and one Marker sprite.

Explore the Stage and decide where each continent is located.

### 2. Create Seven Markers

Duplicate your Marker until you have **7 in total**.

Rename them:

* Africa
* Asia
* Europe
* North America
* South America
* Australia/Oceania
* Antarctica

### 3. Position Your Markers

Place one marker on each continent.

Use each sprite's **x and y coordinates** to help position it accurately.

You can set a starting position with:

```text
when green flag clicked
go to x: ( ) y: ( )
```

Each marker should have its own coordinates.

### 4. Make Your Map Interactive

Program each marker to respond when it is clicked.

For example:

```text
when this sprite clicked
say [I'm Africa!] for (2) seconds
```

Change the message for each continent.

### 5. Test Every Continent

Click the **green flag**, then test all seven markers.

Make sure:

* 📍 Every continent has a marker.
* 🖱️ Every marker responds when clicked.
* 💬 Every marker displays the correct continent name.
* 🗺️ Every marker is positioned correctly.
